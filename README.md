# Telegram 2.0 PRO — starter

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```
Откройте http://localhost:3000

## Демо-вход
1. Введите номер телефона в международном формате.
2. Нажмите «Получить код».
3. Код появится в поле и в консоли сервера — SMS не отправляется.
4. Войдите. Создайте группу кнопкой `＋`, откройте каталог подарков/NFT/маркета.

## Что работает
- Регистрация/вход по демо-коду (без SMS-провайдера).
- Сессия в памяти процесса.
- Групповые чаты, SQLite, сообщения в реальном времени через Socket.IO.
- Загрузка файлов до 15 MB.
- Каталоги подарков, NFT и товаров из SQLite.
- Демо-заказы без реального списания денег.
- Профиль и редактирование имени.

## Важно перед публичным запуском
Это учебный starter, не официальный клиент Telegram и не production-ready сервис.
- Подключить SMS OTP провайдера, rate limiting, CAPTCHA и безопасные постоянные сессии.
- Хранить пароли/токены безопасно, добавить HTTPS, CSRF/CORS-политику и аудит.
- Добавить личные чаты с приглашением/поиском пользователей, права участников, блокировки и модерацию.
- Реальные платежи подключать только через проверяемого платёжного провайдера; не хранить данные карт.
- Для TON/NFT интеграции подключить TON Connect с собственным публичным `tonconnect-manifest.json`, проверять транзакции на сервере и не доверять цене из браузера.
- Для звонков нужен полноценный WebRTC-клиент, signaling authorization и TURN/STUN инфраструктура. Сейчас сервер содержит только базовый relay-события сигналинга, UI звонка не реализован.
- Для production заменить сессии в памяти на Redis/БД, добавить миграции, backup, логи и мониторинг.

Каталоги загружаются из `/api/catalog`; обработчик кликов навигации делегирован на контейнер `.nav`, поэтому переходы не зависят от перерисовки отдельных кнопок.
